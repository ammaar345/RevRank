# RevRank App Preview Video Script

**Duration:** 15–20 seconds (Play Store recommendation)
**Format:** Vertical (9:16) or Landscape (16:9) — recommend vertical for mobile-first
**Style:** Fast cuts, Matrix green/cyberpunk HUD aesthetic, text overlays in Rajdhani/JetBrains Mono
**Music:** Upbeat electronic, building energy, 120–140 BPM

## Technical Notes

- All screen recordings captured on Pixel 7 or similar Android device
- Record in 1080×1920 (portrait) at 60fps
- Apply subtle scanline overlay (2% opacity) to match app aesthetic
- Color grade: high contrast, crushed blacks, lifted shadows
- Keep text on screen for minimum 1.5s per phrase
- First 3 seconds are critical — must show value prop immediately
